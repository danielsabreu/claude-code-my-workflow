## Context

This project builds a publication-ready manuscript and replication package for:

> *"Measuring the Financial Cycle: A Dynamic Factor Model Approach"*  
> Daniel Abreu & Ivan De Lorenzo Buratta

The paper constructs country-specific financial cycle indicators for 10 European economies (BE, DE, ES, FI, FR, GB, IT, NL, PT, SE) using dynamic factor models (DFM). It covers 1995 Q3–2024 Q3 using BIS, OECD, and ECB/ESRB data sources. Target journal: policy/central bank outlet (e.g., IJCB, Economic Policy). No referee reports yet — preparing for first submission.

**Current state:**
- Manuscript lives in `old_overleaf/` (5 section .tex files + main.tex + 3 appendices)
- Code lives in `old_code_and_data/Financial Cycle/3. Codes/CLEAN_VERSION/` (5 R scripts)
- Raw data lives in `old_code_and_data/Financial Cycle/2. Data/` (.RData, .xlsx files)
- Figures are PNGs embedded in the manuscript; tables are hard-coded LaTeX
- The replication package does NOT yet exist as a clean artifact

**Decision:** Raw data is fixed (not re-pulled from APIs). Replication package starts from fixed raw data and runs transformations + analysis.  
**Priority:** Replication package and paper revision proceed in parallel — package drives paper updates.
