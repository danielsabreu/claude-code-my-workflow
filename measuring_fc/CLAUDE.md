## Core Principles

- **Plan first** — enter plan mode before non-trivial tasks; save plans to `quality_reports/plans/`
- **Verify after** — compile LaTeX and run R scripts to confirm output at the end of every task
- **Single source of truth** — `paper/main.tex` is the authoritative manuscript; R scripts in `scripts/R/` generate all figures and tables
- **Replication package drives revisions** — any change to analysis flows into the paper immediately
- **Quality gates** — nothing ships below 80/100
- **[LEARN] tags** — when corrected, save `[LEARN:category] wrong → right` to the root `MEMORY.md`

Cross-session context lives in the root `MEMORY.md`; past plans, specs, and session logs are in `quality_reports/`.
